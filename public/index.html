Sobre o Projeto

Desenvolvido por estudantes para revolucionar o cuidado animal através da tecnologia

Objetivo

Criar um sistema eficiente e de baixo custo que permita monitorar parâmetros vitais e comportamentais dos animais, utilizando sensores conectados a uma rede NB-IoT, com os dados sendo armazenados e processados em um servidor local.

Funcionalidades

Monitoramento completo com tecnologia de ponta

Monitoramento Cardíaco

Acompanhamento em tempo real dos batimentos cardíacos dos animais com alertas automáticos.

Controle de Temperatura

Sensores DHT11/DHT22 para monitoramento da temperatura corporal e umidade ambiente.

Rastreamento GPS

Localização precisa dos animais com histórico de movimentação e geofencing.

Análise de Movimento

Acelerômetro e giroscópio MPU6050 para monitorar atividade e comportamento.

Relatórios Detalhados

Gráficos e análises completas dos dados coletados com exportação em PDF.

Alertas Inteligentes

Notificações automáticas para situações que requerem atenção imediata.

Tecnologia

Stack tecnológico moderno e confiável

Hardware

Software

Node.js Runtime JavaScript para servidor
Express.js Framework web para APIs
Lowdb Armazenamento em JSON
